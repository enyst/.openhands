# Company Values

Define your culture before it defines itself.

## When to use

When you're hiring your first person, or when you realize you've been operating on implicit values that need to be made explicit.

## The principle

Values aren't aspirational posters. They're decision-making frameworks. When you face a hard choice (fire this customer? raise prices? say no to a feature request?), values tell you what to do. If your values don't help you make hard decisions, they're not values — they're decoration.

## How to apply

1. **Look at decisions you've already made.** What did you choose when it was hard? That reveals your actual values, not your aspirational ones.

2. **Write values as trade-offs, not virtues.** Not "we value quality" (everyone says that). Instead: "We ship on time even if it means cutting scope" or "We choose simplicity over features."

3. **Each value should make some people disagree.** "We value honesty" is not a value (who values dishonesty?). "We share our revenue publicly" is a value — some companies would never do that.

4. **Keep it short.** 3-5 values. If you have 10, nobody remembers them.

5. **Test each value:** Would this help you make a hiring decision? A product decision? A customer decision? If not, cut it.

## Output

- 3-5 company values, each stated as a concrete trade-off
- For each: a real example of a decision this value would guide
- What the value means you WON'T do (the trade-off)

## Anti-patterns

- Values that nobody disagrees with ("we value excellence")
- More than 5 values
- Values created by committee instead of by the founder
- Values that don't change behavior
