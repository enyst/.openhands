# Minimalist Review

Gut-check any decision against minimalist entrepreneur principles.

## When to use

Before any significant decision — launching a feature, hiring someone, raising money, changing pricing, picking a market. The minimalist review is a quick sanity check.

## The principle

Most startup mistakes come from doing too much, not too little. The minimalist review asks: is this the simplest version of this decision? Am I doing this because it's needed, or because it feels like what a "real company" would do?

## How to apply

Run through these questions for any decision:

### The basics
- [ ] Does this serve my existing community?
- [ ] Have I talked to customers about this? (Not assumed — actually talked)
- [ ] Can I test this without building it?
- [ ] What's the simplest version of this?

### The money check
- [ ] Does this increase revenue or decrease costs?
- [ ] Can I afford this from current revenue? (Not "future revenue" — current)
- [ ] If this fails, do I still survive?

### The time check
- [ ] Can I do this in a week? If not, can I scope it down until I can?
- [ ] Am I doing this because customers asked, or because I think they should want it?
- [ ] What am I NOT doing while I do this?

### The honesty check
- [ ] Am I doing this because it's needed, or because it looks impressive?
- [ ] Would I do this if nobody was watching?
- [ ] Is this what a company my size should be doing, or what a company 10x my size does?

## Output

A go/no-go decision with reasoning for each checklist item. If more than 3 items are "no," reconsider the decision.

## Anti-patterns

- Skipping the review because you're excited
- Rationalizing "no" answers into "yes"
- Using this as an excuse to never take risks (the review is for scope, not for courage)
