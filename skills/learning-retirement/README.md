# Learning retirement

A small independent adaptation of the conditional-learning idea in
[Compound Engineering's YAML guidance](https://github.com/EveryInc/compound-engineering-plugin/blob/50532b00de523980010d97fe950965b35382a3b7/skills/ce-compound/references/yaml-schema.md).
It adds no scheduler, Git hook, dependency or automatic deletion. The existing
project knowledge format remains authoritative. It does not import the full
`ce-compound` workflow or its session-history readers.
